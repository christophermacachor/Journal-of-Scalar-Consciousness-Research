## I. THE MACACHOR FUNDAMENTAL LAW

> **A fundamental cannot be extracted from the emergent as though the emergent were its ontological source.**

The emergent may reveal the fundamental, but revelation is not creation.

### Core Formulas (Plain-Text Notation)

```

from which it emerges.
```

**Direction of Fundamentality (Ontological):**
```

```

**Direction of Knowledge (Epistemic):**
```

```

These arrows are different: the first is ontological; the second is epistemic.

**Non-Reversal Principle:**
```
A → B does not imply B → A
```
when A is ontologically prior to B.

**Perturbation:**
```
Perturbation = Change relative to an existing structure

Structure → Perturbation
```
Not:
```
Perturbation → Structure
```

**Resonance:**
```
Excitation + Characteristic Frequency → Resonant Response

Excitation ≈ Characteristic Frequency → Resonance
```
The ≈ means "approximately matches," not mathematical identity.

**Wave Distinction:**
```
Wave ≠ Frequency
Wave ≠ Scalar Substrate
Wave = Emergent / Propagating Perturbation
```

**Vector Distinction:**
```
Vector = Magnitude + Direction
Scalar = Magnitude without intrinsic Direction
```

### The Complete Macachor Hierarchy

```
Scalar Substrate → Invariant → Frequency → Perturbation → Vector → Wave → Resonance
```

The epistemic reconstruction is:

The epistemic arrow does not reverse the ontological arrow.
